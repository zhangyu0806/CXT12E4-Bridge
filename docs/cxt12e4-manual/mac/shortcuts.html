三键组合

Caps + Shift + 实体 Win

Caps 代替 Command。普通应用与终端都可这样按；Shift 与 Caps 的先后顺序均兼容。下表“三键”均指这个组合。

窗口与多屏

三键 = Caps + Shift + 实体 Win。针对当前窗口，不用先切回 Codex。

按键作用使用范围 / 提醒
三键 + ↑ / ↓上半屏 / 下半屏当前显示器内分半；不是移到上、下两台显示器。
三键 + ← / →左半屏 / 右半屏当前显示器内分半。
三键 + L当前窗口移到右侧竖屏并铺满固定右侧 U2777B；重复按保持铺满，三键 + R 恢复。
三键 + A铺满 / 恢复左侧窗口跨上下双屏并隐藏菜单栏；右侧窗口铺满右屏。再次按恢复；单屏时退回当前屏最大化。
三键 + Space → 跨两屏 / 恢复当前窗口跨左侧上下两屏 / 恢复保留菜单栏。原 S 操作从布局菜单选择；接入 Sidecar 后仍使用指定左侧双屏。
三键 + R恢复当前窗口保存的位置恢复本轮调整前的位置；与 Win + ↑ 的即时尺寸分别保存。
三键 + 1 / 2 / 3 / 4移到对应编号的显示器编号按从左到右、同列从上到下排序；缺少该屏时不执行。
三键 + Space打开布局菜单单屏最大化、四角四分之一、居中 80%、移屏、四套固定方案与整套撤销；Esc 取消。
Win + ↑当前屏最大化保存此前尺寸；再次按保持最大化。
Win + ↓恢复尺寸 / 最小化最大化后先恢复，再按最小化；普通窗口直接最小化。
Win + ← / →当前屏左半 / 右半单窗口操作。
Win + Shift + 方向键移到相应方向的相邻显示器普通窗口尽量保持尺寸；最大化窗口继续最大化。原生全屏需先退出。

本次核对的编号：1 左上 LG · 2 左下 27C1U-D · 3 右竖 U2777B · 4 iPad Sidecar。插拔或重新排列后编号可能变化；L 与 Z/X/C/S 使用固定显示器身份。

Caps 与输入

T90 的 Caps 在普通应用相当于 Command，在终端相当于 Ctrl。

按键作用使用范围 / 提醒
Caps + C / X / V复制 / 剪切 / 粘贴普通应用中。
Caps + A / Z / S全选 / 撤销 / 保存普通应用中；终端按 Ctrl 的含义处理。
Caps + C发送 Ctrl + C，中断当前任务终端中，不能当作复制。
Caps + V粘贴终端专门适配为 Command + V；在 tmux 复制模式也不是矩形选择。
Caps + Stmux 前缀接入 tmux 后，松开组合再按后续键。
Shift + Caps 短按切换大小写锁定T90 在松开时触发；只点 Caps 不切换大小写。
Fn / Globe 单按切换输入法Fn + 数字则用于应用快启。

左 Alt + 0鼠标右键点击在当前指针位置点击。

tmux：直接按

需处于已接入 tmux 的终端。这里的 Alt 可用 T90 实体左 Alt；被上方编辑 / 鼠标层占用的组合另行注明。

按键作用使用范围 / 提醒
F1 … F10切到编号 1 … 10 的已有会话当前 T90 在 Ghostty / Terminal 已适配直接发 F 键；没有对应会话不创建。
F12切到编号 11 的已有会话F11 保留为应用原生全屏。
Alt + 1 … 8切当前会话的窗口 1 … 8第 9 窗口用前缀 → w 选择。左 Alt + 9 仍是鼠标点击。
Alt + 方向键切到相邻 pane使用真正的 ← ↓ ↑ →，不是 H/J/K/L。
Alt + [ / ]前一个 / 后一个 pane方括号。
Alt + F放大 / 恢复当前 pane小写 f，不按 Shift。
Alt + O在当前目录新建 tmux 窗口小写 o，不按 Shift。
Alt + Shift + O把当前 pane 拆到独立窗口当前会话内。
Alt + Shift + S新建会话明确的新建操作。
Alt + Shift + Q直接关闭当前 pane会结束其中任务，无确认；最后一个 pane 关闭后窗口结束。
Alt + Shift + H / J / K / L向左 / 下 / 上 / 右调大 pane每次 3 格。
Alt + Shift + 1 … 9把当前 pane 移入指定窗口移动的是当前 pane，目标是窗口 1 … 9。
Alt + V进入复制模式小写 v，不按 Shift。
Alt + P从光标选择到行尾会进入复制模式；已补齐终端适配。
Caps + V终端粘贴Caps 的专用粘贴例外。
Ctrl + V / Ctrl + O粘贴系统剪贴板实体 Ctrl；复制模式内 Ctrl + V 为矩形选择。
Alt + Shift + V / Ctrl + Shift + V粘贴系统剪贴板可退出复制模式后粘贴。
Alt + Shift + T保存 tmux 工作区快照保存窗口和 pane 布局。
Alt + Shift + R恢复已保存快照按现有恢复保护规则执行；不是单个 Agent 重启。
Command + Shift + ,重新加载 Ghostty 配置用真正 Command；终端 Caps 在这组仍为 Ctrl，不能替代。

tmux 用于连接已有工作区；没有运行会话时，现有恢复脚本可能恢复保存的工作区。需要明确新建时用 tmux new。普通 Alt 组合能否传入，取决于终端的 Option / Meta 设置；当前主要按 Ghostty 核对。

tmux：先按前缀

前缀 = Caps + S / Ctrl + S，松开后再按下面的键。字母大小写分开写，避免误触。

按键作用使用范围 / 提醒
前缀 → s打开会话树选择已有会话。
前缀 → w / Shift + W打开窗口树可以选择第 9 窗口，避开左 Alt + 9。
前缀 → f搜索窗口按名称查找。
前缀 → c当前目录新建窗口当前 session 内。
前缀 → Ctrl + Q新建会话明确新建。
前缀 → d脱离 tmux会话和其中任务继续运行。
前缀 → Shift + D选择客户端管理终端连接。
前缀 → ,重命名当前窗口逗号。
前缀 → .重命名当前会话句号；使用现有编号管理规则。
前缀 → $原生重命名会话Shift + 4。
前缀 → Ctrl + P / Ctrl + N前一个 / 后一个窗口先松开前缀，再按 Ctrl 组合。
前缀 → Alt + P / Alt + N前一个 / 后一个有活动的窗口按 tmux 的 activity 标记；不是输入正在运行与否。
前缀 → 1 … 9 / 0把整个当前窗口移到指定会话1 … 9 对应会话 1 … 9，0 对应 10；不是切换窗口。
前缀 → l / y当前会话顺序左移 / 右移小写 L / Y；也可用前缀 → ( / )。
前缀 → h / j / k向左 / 下 / 上新分 pane小写；右侧分屏用下一项。
前缀 → %向右新分 paneShift + 5；小写 l 已用于会话顺序左移。
前缀 → Space切换两 pane 横竖布局恰好两个 pane 时。
前缀 → Shift + H / J / K / L构建左 / 下 / 上 / 右三格布局需要恰好两个 pane，会新增 pane；上 / 下三格要求原为左右布局。
前缀 → < / >与前一个 / 后一个 pane 交换位置Shift + 逗号 / 句号。
前缀 → |交换 pane竖线。
前缀 → Shift + S / Shift + V树选 pane 并合入上下 / 左右排列。
前缀 → Ctrl + G同步输入开关开启后会向多个 pane 同时输入；再次按关闭。
前缀 → r重新加载 tmux 配置小写 r。
前缀 → Shift + R重启当前 pane 的已记录任务例如退出到 shell 后，重启此前记录的 Agent。
前缀 → &关闭当前窗口确认后执行。
前缀 → Ctrl + W关闭整个会话确认后执行。
前缀 → x关闭当前 pane确认后执行。
前缀 → b列出 tmux 复制缓冲查看 tmux buffer。
前缀 → p粘贴 tmux 缓冲与系统剪贴板粘贴分开。
前缀 → ?查看当前 tmux 键位以运行中的实际绑定为准。
