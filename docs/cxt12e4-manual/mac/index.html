操作普通操作按住 RT

LT 按住精细移动；Menu ≡ 短按打开任务 / 会话选择，长按约 0.85 秒暂停或恢复手柄。A / B / 方向键在选择面板内用于确认 / 取消 / 选择。

八层默认统一：X 左键 / 按住拖拽，Y 右键，A 回车确认，B Esc。Codex 层按下右摇杆 R3 发送 Tab，RT + R3 为中键；其他层 R3 仍为中键。A 发送 Enter，具体作用取决于前台应用；在终端会执行当前输入。RT + L3 执行本层专用动作，L3 单按仍打开本层设置。Xbox、View、分享键保留系统用途。普通切窗或切层会保留已经开始的拖拽；摇杆模式改变后须先回中。断连、休眠、暂停或修改配置会释放已按住的鼠标键；恢复时先松开按钮、扳机并让摇杆回中。

Mac 实测 · 按顺序确认

2026-10-20 已实机确认 X 拖拽、Y 右键、B 关闭菜单及 Menu → A 选择确认。本次新增的 Codex R3 Tab 与其他分层功能仍请逐项确认。

先测基础操作，再测 Codex / 终端 / Notion
  1. 连接与回中：按 Xbox 键唤醒，在 Bridge 菜单检查手柄状态；松开所有按钮、扳机和摇杆。只有显示已连接、未暂停，才继续测试。
  2. 鼠标：左摇杆移动指针，按住 LT 应更慢；X 单击，按住 X 拖动一个窗口后松开，确认拖拽结束。Y 应打开右键菜单，B 应发出 Esc；在安全的测试对话框中用 A 确认。
  3. 滚动：在较长网页上推右摇杆上下滚动；页面应响应，摇杆回中后停止。Blender 层右摇杆默认旋转视角，不是网页滚动。
  4. Menu：短按应打开任务 / 已有会话面板，LB / RB 切组，B 取消；普通应用中长按约 0.85 秒暂停，左摇杆不再移动，再长按恢复并回中。
  5. 分层：切到 Codex、Ghostty、Notion，菜单栏数字依次应为 1、2、3。Codex 的 RT+L3 聚焦输入框，按下右摇杆 R3 发送 Tab，RT+R3 保留中键；Notion 的 RT+L3 打开快速搜索。RT+A / B 默认复制 / 粘贴；粘贴先用无执行风险的短文本确认，不发送回车。
  6. 已有 tmux：在现有 session 中测试 RT+L3 缩放 pane，RT+十字键切 pane，RT+LB / RB 切已有 session。Menu 选择已有会话后，会话总数不应增加；没有会话时面板应显示空态。
  7. 独立配置：在菜单栏“分层按键设置…”里只修改 Xbox 的一个层，确认 12E4 同层与 Xbox 其他层不受影响；再恢复本层默认。记录出问题的应用、层号、按钮和实际结果。

Windows 使用同一分层思路，L6 是 Total Commander，终端 RT 快捷键与滚轮单位也不同；请查看 Windows 对应层说明，不要直接导入另一平台的配置。

Codex 六任务状态灯

所有层中，键1、2、3、5、6、7始终对应任务1–6并显示实时状态；当前层指示灯另外叠加显示。

白色 · 空闲 / 已查看任务空闲或已查看；主动停止也恢复白色。
深蓝动态 · 思考中亮度流动/闪烁，表示任务正在运行。
深绿色 · 已完成新结果尚未查看；打开任务后恢复白色。
琥珀黄 · 等待输入任务暂停，正在等你的回答或操作。
红色 · 出错任务出现错误，需要打开检查。

启动、权限与输入
  • 菜单栏“使用说明”打开本页的在线版本；“快捷键总表”打开 新域名首页。“离线说明”打开应用内随版本附带的说明与完整手册，断网时可用。在线版更新与已安装版本可能不同。
  • 首次安装：从 项目仓库获取源码，按 Mac 安装说明执行 ./install/macos/install.sh。需要 macOS 13+、Xcode Command Line Tools、Python 3 和已启用的 Karabiner；tmux 另需对应依赖。三屏布局、Caps 与普通键盘数字快启是独立配置示例，不由 Bridge 安装器自动部署。
  • “应用程序”中的 CXT12E4 Bridge 登录时自动启动。菜单栏与 Win11 一致，使用八层对应颜色的正方形色块，中央粗体数字 1–8 显示当前层；L1、L4 白字，其余黑字。悬停显示层名、自动或手动模式及连接状态；菜单勾选标明当前层及是否自动切层，也可手选层。
  • 开启 Bridge 的辅助功能和输入监控，并保持 Karabiner 运行。12E4 专用输入规则仅匹配此设备。
  • 短按在松开时执行；长按650ms进入对应任务或会话，长按后不再追加短按。键12组合沿用原应用位。普通按键组合与旋钮私有标记互斥，重叠或异常报告会取消本轮，释放全部按键后再操作。
  • 12E4 默认 K4 在各层发送加速纵向滚轮，按下功能依当前层；分层设置可覆盖短按与旋钮动作，长按和键12应用组合保持固定。
Xbox 分层设置与暂停
  • 菜单栏 → “分层按键设置…” → 选择 12E4 或 Xbox → 选择 L1–L8 → 修改对应操作。两设备共用当前层，各层覆盖互相独立；未设置的控件使用该层默认值，“恢复本层默认”会重置整个当前设备当前层，包括该层其他自定义项；若只想改四个面键，请单独修改 A / B / X / Y。升级会保留已有自定义覆盖，写入配置的旧映射不会被默认更新替换。
  • 左摇杆默认鼠标、右摇杆默认双向滚动；Blender 层右摇杆默认旋转视角。设置页可改摇杆模式、死区、鼠标速度、滚动速度、LT 精细倍率及滚动方向。
  • 设置窗口内：映射修改立即保存；手柄 A 完成，B 或 Menu 关闭，都会先保存并校验未保存的参数，输入有误则保留窗口和错误提示。B 在这里不是撤销；要放弃未保存参数，请先点“撤销修改”。方向键交给当前输入框或下拉框，Menu 不会再叠开任务选择面板。
  • 手柄 Menu 短按打开两组选择：Codex 最近任务、tmux 已有 session；方向键移动，A 确认，B 或 Menu 取消。所选项按稳定身份打开，不会随最近列表刷新而跳到另一个槽位。没有应用启动组，也不会新建 tmux 会话。切去其他应用会自动关闭选择面板，不抢回焦点。
  • 手柄 Menu 长按或菜单“暂停 / 恢复 Xbox”只暂停手柄。也可用“在当前应用暂停 / 恢复 Xbox”记录当前应用，或在设置里填实际游戏的 Bundle ID。默认列表仅含 Steam 和 Games 启动器，不等于自动识别全部游戏；游戏进程需单独添加，或进入游戏前手动暂停。处于应用暂停名单时，连 Menu 也保留给前台应用；恢复请用菜单栏或离开该应用。普通应用中的手动暂停仍可长按 Menu 恢复。
  • 手柄按键未独占：暂停名单之外的前台游戏仍可能收到原始输入。Xbox、View、分享三键由系统处理，本版本不接管。X 拖拽、Y 右键、B 关闭菜单及 Menu → A 选择确认已实机通过；精细移动、跨层手感与本次新增的 R3 Tab 仍需实测。
tmux 六灯与会话
  • 终端输入 tmux 连接已有会话；没有会话时不会自动新建，需要时显式输入 tmux new。自动恢复和开机启动仍关闭。
  • 键9、10、11、12、8、4依次对应 tmux 灯位1–6，长按切入对应的现有会话。
  • 01–06 开头的会话固定对应灯位；默认数字名或普通项目名自动分配空闲灯位，已有分配不会因其他会话退出而前移，重启 Bridge 后保留。
  • 没有会话的灯位熄灭；普通 shell 空闲为白灯。重复固定编号会关闭对应灯位并拒绝切换。
  • 已运行的 Claude Code / OpenCode 需重启一次才能加载状态 hooks。白为空闲，蓝为运行，绿为新完成，黄为等待，红为真正错误；主动停止任务恢复白色，不作为错误。
