配置与使用说明

与你原来的 Karabiner 规则配合使用。

你原有的键盘习惯

T90 左 Alt+H/J/K/L 继续作为普通方向键，用于编辑文字；左 Alt+9/0 继续用于鼠标点击。切 tmux 面板用 Option+实际方向键。Caps/Fn 数字启动应用、物理 Win 键和 12E4 设备专用规则保持原样。

本次同步内容
  • winsettings 核心配置、shared.conf 的会话管理、portable profile，以及已安装的三个固定版本插件。
  • CXT12E4 的 Mac 适配负责新窗口、Agent 退出后的 shell 恢复和手动重启，并补齐本机布局恢复使用的 Agent 白名单。
  • 直接输入 tmux 默认连接已有会话，不再额外创建数字会话。新默认已对当前终端立即生效，无需重开 shell。没有现有会话时使用 tmux new 明确新建；自动恢复和开机启动仍关闭。
  • 为 tmux 提供 Bash 5、Python 3.12、fzf 和 GNU 工具；本机适配层处理 Darwin 的进程年龄及子进程查询。
  • 安装脚本给 Ghostty 添加受管配置：开启 Option→Meta，取消 Option+左右方向键的词移动绑定，让 tmux 接收方向键。
  • Mac 快捷键适配补齐 Ghostty 扩展按键编码下的 Shift 组合。Option+O 使用本机会话上下文新建窗口，避免旧目标表达式导致创建失败。
  • 已关闭微信输入法 WeType 的 Option+Shift+H 全半角切换快捷键，解除对 tmux 调整面板大小的占用。
  • 已有会话加入保护名单，避免被数字临时会话清理规则删除；共享编号逻辑可能调整显示名称，会话本身继续保留。
配置与备份位置
  • 共享配置来源：~/code/winsettings。Mac 通用适配来源：CXT12E4 仓库的 integrations/tmux/macos/，可在其他 Mac 重新安装。
  • 入口：~/.tmux.conf → ~/code/winsettings/tmux/tmux.conf。
  • 本机配置：~/.config/tmux/local.conf，安装时保留用户内容并追加受管配置入口。
  • Mac 适配：~/.config/tmux/macos/；辅助工具：~/.config/tmux/macos-bin/。
  • 快捷键兼容：~/.config/tmux/macos-keys.conf，补齐扩展编码下的 Option+Shift 组合及 Ctrl+Shift+V，并兼容复制模式中的粘贴。
  • Ghostty：~/Library/Application Support/com.mitchellh.ghostty/config.ghostty。
  • 同步前的 tmux 入口、本机配置、Ghostty、Karabiner 备份：~/.local/state/tmux-macos-backups/20261008-155143。
  • 适配安装备份：~/.local/state/tmux-macos-backups/<timestamp>-setup/。
  • 原来的 ~/code/tmux-portable 和本地兼容性提交保留。
在其他 Mac 重建

准备本地 winsettings 仓库。适配要求 tmux、Bash 4 及以上、Python 3.10 及以上、GNU coreutils / findutils 和 fzf；本机使用 Bash 5、Python 3.12 验证。建议安装 Homebrew 当前版本，再复用 winsettings 的固定版本插件安装流程：

brew install tmux bash python coreutils findutils fzf

bash /path/to/winsettings/tmux/install.sh --apply --plugins

在 CXT12E4 仓库先预览；未带 --apply 时只检查和生成计划：

python3 install/macos/setup_tmux.py --winsettings /path/to/winsettings

python3 install/macos/setup_tmux.py --apply --reload --winsettings /path/to/winsettings

安装保留 local.conf 用户内容并添加受管入口，备份被修改的文件。自定义 tmux 入口未加载 local.conf，或已有 winsettings 链接指向其他来源时，安装会拒绝覆盖。Bridge 安装脚本自动尝试此流程：找不到仓库时提示跳过；找到仓库但缺依赖或固定插件时明确报错，此时已有 Bridge 仍在运行。

此前只保存在本机的快捷键和进程工具现由仓库模板提供。自定义保存策略规范记录三种 Agent 名称，恢复策略在对应面板先登记 Agent 再执行，支持后续退出回 shell 和 Shift+R 重启。两种策略均不修改上游插件源码；手动恢复只启动本机可用的程序，缺少程序时回到 shell。私有设置及会话快照仍各自保留；没有启用自动跨机发布会话状态。新 Mac 安装后，用 ⌘+Shift+, 加载 Ghostty 配置，并检查 WeType 的 Option+Shift+H 是否被全半角切换占用。
