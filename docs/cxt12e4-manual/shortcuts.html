Windows 快捷键

集中查看现有 Windows Bridge 与可选 WSL 配置使用的普通键盘组合。按应用和场景查找；12E4、手柄的完整控件图从对应设备页进入。

先看适用应用

Ctrl / Alt / Shift / Win 是 Windows 键盘的修饰键；“+”表示同时按。“/”分隔一组对应操作。同一组合在浏览器、终端和笔记应用中可能不同。

这里是当前项目的快捷键参考，不是完整私人 AHK 总表，也不会为所有应用新增全局快捷键。应用自身改键和 Bridge 自定义覆盖以本机为准。

tmux 的“前缀 → 键”

先按本机 tmux 前缀，松开，再按后面的键。已有配置若使用 Ctrl + S 前缀，就先按 Ctrl + S；本页不假定新安装已配置该前缀。

普通键盘绑定与 Bridge 设备动作分别生效。可选 WSL 部分需要已有 tmux 环境和对应绑定。

编辑与浏览器

前台应用需支持这些组合；同一组合在不同应用中可能有不同作用。

普通键盘按键作用适用范围 / 提醒
Ctrl + X / Ctrl + C / Ctrl + V剪切 / 复制 / 粘贴普通编辑框；在 Windows Terminal 中使用下方的终端组合。
Ctrl + Z / Ctrl + Y撤销 / 重做通用层默认组合；Blender 重做使用 Ctrl + Shift + Z。
Ctrl + Shift + V纯文本粘贴浏览器与支持此组合的应用；终端中通常是普通粘贴。
Ctrl + F查找浏览器 / 当前应用；Windows Terminal 搜索使用 Ctrl + Shift + F。
Ctrl + T / Ctrl + Shift + T新标签 / 恢复关闭的标签浏览器。
Ctrl + Tab / Ctrl + Shift + Tab下一个 / 上一个标签浏览器和支持标签切换的应用。
Ctrl + W关闭当前标签应用决定是否关闭标签、文档或窗口。
Alt + ← / Alt + →后退 / 前进浏览器。
Ctrl + L聚焦地址栏浏览器；Notion 中同组合用于复制页面链接。
Ctrl + − / Ctrl + + / Ctrl + 0缩小 / 放大 / 恢复 100%浏览器与支持缩放的应用。
F5刷新浏览器；Total Commander 中同键是复制文件。
Ctrl + ← / Ctrl + →向前 / 向后移动一词文本编辑框；具体分词由应用决定。
Ctrl + Alt + C / Ctrl + Alt + VPixPin 截图 / 贴图需要 PixPin 已运行，并使用对应快捷键设置。
Win + 1…9 / Win + 0启动或切换任务栏第 1–10 个应用Windows 任务栏顺序；12E4 的键 12 应用组合使用同一入口。

可选 WSL / tmux 绑定

以下是仓库附带的可选绑定。已有 tmux 配置加载这些绑定后才生效；前缀以本机设置为准。

普通键盘按键作用适用范围 / 提醒
Alt + O在当前目录新建 window直接按，不需要 tmux 前缀。终端必须把 Alt + O 交给 tmux。
前缀 → c在当前目录新建 window先按前缀并松开，再按 c。
前缀 → h / l在左侧 / 右侧新建 pane沿用当前 pane 的目录。
前缀 → Ctrl + H左右切换 pane右侧有 pane 时向右，否则向左返回；仅当前 window。
前缀 → Ctrl + J上下切换 pane下方有 pane 时向下，否则向上返回；仅当前 window。
前缀 → Ctrl + E / Ctrl + R横向 / 纵向均分 pane作用于当前 window。
前缀 → Ctrl + P / Ctrl + N上一个 / 下一个 window作用于当前 session。
前缀 → Ctrl + B回到上一个使用的 window在当前 session 中切回。
前缀 → Ctrl + S暂存 / 恢复 Agent 未发送的输入需要 cxt-l2-agent-action；支持 Claude Code / Grok，OpenCode 还需 prompt_stash=ctrl+s。

前缀按顺序使用：若本机前缀设为 Ctrl + S，“前缀 → Ctrl + S”就是按一次 Ctrl + S，松开，再按一次 Ctrl + S。本页不更改你的 tmux 前缀。

WSL 安装器安装 Agent helper 与状态 hooks，不会覆盖整套 tmux 配置或自动启用以上绑定。现成完整配置属于个人环境，不随公开项目提供；请在自己的配置中采用所需绑定。Bridge 的 L2 大部分设备动作直接调用 tmux，不要求先按普通键盘前缀。

没有匹配的快捷键。试试动作名称，或切回“全部”。

12E4 与手柄的关联入口

12E4：长按 1 / 2 / 3 / 5 / 6 / 7 约 650 毫秒切任务；长按 9 / 10 / 11 / 12 / 8 / 4 切 tmux 灯位 1–6；按住 12 再按其他键，松开后启动对应任务栏应用。

Xbox：Menu 短按打开任务 / 会话面板，长按约 0.85 秒暂停或恢复手柄；L3 单按打开当前层设置。应用暂停名单内请用托盘恢复或离开该应用。
