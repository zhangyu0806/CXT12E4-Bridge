Xbox · 同层独立设置

菜单栏 → 分层按键设置… → 选择 Xbox 或 12E4 → 选择层 → 修改控件动作。两设备共用当前应用层，映射独立保存；未覆盖的控件继承该层默认值，恢复本层默认会重置整个当前设备当前层（含其他自定义项）。升级保留已有覆盖；只想改 A / B / X / Y 时请单独修改。12E4 长按任务 / 会话与键12应用组合保持固定。

灯光

Codex 六任务（Mac / Windows 统一）：白：空闲、已查看或手动停止　蓝：运行中　绿：完成未查看　黄：等待输入　红：明确失败。通过 12E4 任务键或 Xbox 选择面板成功打开已完成任务后转白；查看确认只对应当前轮次并持久保存，重启 Bridge 后仍为白色。尚未查看的完成保持绿色；下一轮运行转蓝、完成后重新亮绿。手动停止转白，不算错误。等待你回答时亮黄，包括边工作边提问；对应问题全部回答后，若仍在运行则转蓝，最终完成转绿。

本地 Codex 任务若在电脑关机或重启前仍记为运行、且没有结束事件，Bridge 会根据本机启动时间将这次中断恢复为白色；已有完成记录按是否已查看保持绿色或白色。Bridge 不凭运行时长判定完成。同一次开机期间若缺少结束记录，仍无法可靠确认任务是否已结束。

tmux 会话：绿灯表示新完成；长按对应灯位切入并确认后转白，历史完成记录不会在重启后重新点绿。白为空闲，蓝为运行，黄为等待，红为真正错误。各层对应键 1–8 的双呼吸是层提示；没有任务或 session 的灯位熄灭。

tmux 使用这台 Mac 的本地会话。默认名称 0、1 或普通项目名会自动分配空闲灯位；01 至 06 开头的名称则固定对应灯位。已有自动分配不会因其他会话退出而前移，重启 Bridge 后也保留。首次可直接运行 tmux new；普通 shell 空闲时亮白灯，没有会话的灯位熄灭。多个终端客户端同时连接时，L2 直接操作会拒绝猜测；长按 session 灯位仍切换最近活动的客户端。选择面板用 session ID、创建时间与 server 身份校验现存目标；多窗口无法唯一定位时会提示确认终端窗口。普通 tmux 只连接已有会话，需要新建时明确输入 tmux new。已在运行的 Claude Code / OpenCode 需重启一次才能加载状态灯 hooks。

Mac 上的对应方式

Finder 的复制/移动遵循 Mac 的复制粘贴方式。键 10 用 Cursor 比较两个选中文件；键 11 预览两个选中目录的复制更新，确认后执行，保留目标中其他文件并备份被覆盖文件。第一次读取 Finder 选择时可能需要允许自动化控制。

Notion 键10 / 11 的待办块 / 代码块使用 ⌘+Option+4 / 8。通讯键8发送、键9清空、键11换行仅在已聚焦的可编辑消息输入框执行；搜索框或会话列表不执行。Finder 键6逐行复制文件名，读取失败时保留剪贴板。Notion、Obsidian 的菜单命令和不同通讯软件的快捷键依赖应用版本。未找到明确控件时，菜单栏会提示。Blender 需要默认键位。这里没有迁移 Windows 正在运行的会话。

首次检查：系统设置 → 隐私与安全性，开启 CXT12E4 Bridge 的辅助功能和输入监控，并保持 Karabiner 开启。切回 Codex 后按键 9 两次，再转动 K4，检查侧栏和滚动。

各层覆盖及手柄参数保存在 profiles.json，上次设置备份为 profiles.previous.json。配置变更前的备份、运行日志和状态在 ~/Library/Application Support/CXT12E4Bridge/。键盘固件未改动，接回 Windows 仍可使用原 Bridge。
